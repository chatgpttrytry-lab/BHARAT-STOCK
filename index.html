Technical indicator notes
RSI, MACD, EMA and Bollinger Bands are not computed in this prototype. These require a reliable historical OHLCV data feed. The chart uses historical Yahoo Finance price points when available; if the feed fails, the status below the chart explicitly identifies the sample fallback. Charts are informational, not trading signals.

About data & privacy

This is a client-side demo. Your watchlist, portfolio and preferences are saved in this browser using localStorage. No account or server is used. Do not store sensitive financial credentials here.

For production use, integrate a licensed NSE/BSE market-data provider through a secure backend. Never expose secret API keys in a public HTML file.
